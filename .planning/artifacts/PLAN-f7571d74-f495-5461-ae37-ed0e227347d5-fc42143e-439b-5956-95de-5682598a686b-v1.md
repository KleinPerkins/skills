## Implementation scope retained from the accepted proposal

Keep bootstrap.sh as the sole installation entrypoint and extend it with one opt-in, deliberately restricted selection transaction. Do not create a second user-facing installer, change per-skill lifecycle ownership, add dependency metadata or alter default fleet behavior.

Proposed interfaces (not implemented):

```text
bash <durable-source>/bootstrap.sh --scoped-preview <selection.json>
bash <durable-source>/bootstrap.sh --scoped-apply <selection.json> --receipt <receipt.json>
bash <durable-source>/bootstrap.sh --scoped-rollback <receipt.json>
```

These forms are mutually exclusive with every existing mode/flag. Reject missing, unknown, duplicate or combined flags before clone, metadata enumeration, registry access, temporary output or mutation. No default source cloning and no HOME override may be used for the real canary.

Initial supported selection is deliberately closed to the **two global flavor-1/post_mgmt-none skills agent-route and ecosystem-search, client codex**. It may select exactly those two for this operation; reject other clients, IDs, shelves, kinds and runtime contracts. This bounded design avoids adding a general multi-capability migration framework. Ordinary bootstrap retains its behavior without any new flag.

Use the current recognized standalone Skills root as the source; require actual Git top-level/origin/clean bytes and explicit expected source revision/tree. Reject linked authoring worktrees in scoped mode instead of redirecting to primary. No arbitrary --source-root, copy, PATH command, package installation or fallback. Reuse capability_meta.py's strict parse/field validation for exact selected paths and require metadata to expose codex. An existing parser entrypoint can be factored without changing unscoped semantics; avoid recursive metadata discovery in scoped mode. Preserve explicit opt-outs; never read/reset unrelated plugin state to select two skills.

Selection file proposed closed shape:
```json
{
  "schema": "skills-scoped-install/v1",
  "operation_id": "<fresh unique operation id>",
  "source": {"root": "<durable standalone source>", "revision": "<verified follow-up merge>", "tree": "<verified tree>"},
  "client": "codex",
  "capabilities": ["agent-route", "ecosystem-search"],
  "parent": {"path": "/Users/laurence.duggan/.codex/skills", "device": "<observed integer>", "inode": "<observed integer>", "uid": 503, "gid": 20, "mode": "0755"},
  "targets": [
    {"id": "agent-route", "before": "<exact existing symlink lstat and target>", "after": "<derived same-root skill link>"},
    {"id": "ecosystem-search", "before": {"type": "absent"}, "after": "<derived same-root skill link>"}
  ],
  "expected_action_sha256": "<hash of normalized source, selection, parent, preimages and derived writes>"
}
```
Angle-bracket fields are explicit unresolved typed values, not executable inputs or permission tokens. The current exact preimages and desired link targets are in proposed-delta.json. Preview computes the action digest; apply requires the exact resulting selection and an unused private receipt path. The digest binds the operation, not user consent. Authorization is established by the approved operation envelope outside this installer; never treat a supplied hash or file as human consent.

Preview returns a closed, serializable two-link plan and refuses unexpected target ownership, real paths, source drift or parent aliases. No installation or shared state change; only stdout output. Apply preflights both links before mutating either, establishes private operation serialization under the target parent, revalidates source/parent/preimages immediately, and records a private mode0600 journal/receipt. Directory handles and no-follow checks prevent redirection; live cooperative writer exclusion remains required because an installer lock does not stop all external writers.

Record each completed link postimage and failure/recovery state. If the second operation fails, restore the first only if its task-owned postimage remains unchanged. Do not call generic run_install, prune, repair or reset-local-config. Record temporary names/locks in the receipt and clear them on normal completion. Rollback consumes the same receipt and restores only matching task-owned postimages. Unknown/missing receipt or drift refuses; interrupted outcomes require readback and a deterministic supported resume/rollback, never blind retry. Reapplication of an already complete exact operation is a verified no-op; a second unrelated receipt cannot adopt its resources.

The helper must own these checks inside bootstrap's mechanism, not expose a generic arbitrary-path symlink library as a public command. Protected-path or owner/admin requirements, if any on the actual files, still apply under the normal approved repository process.
