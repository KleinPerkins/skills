Codex build 23880, an already-installed official `pdf@openai-primary-runtime`
provider at version `26.1026.10807` can fulfill the bounded PDF operations in
`build-23880.json` without publishing another home skill link. The source
checkout remains at its approved migration pin. This alternative applies only
to Codex; metadata and installation routes for other clients are unchanged.

unchanged original payload inventory, enabled native discovery without extra
roots, and personal account identity. A metadata/name match alone is insufficient.

No worker, chat, token refresh, download or external request is needed for this
recorded route. An absent/disabled/different provider does not inherit authority
to install or enable itself from this observation.

table extraction, split, ordered merge, rotation, watermark, AES-256 encryption
and unlock, decrypted output, embedded-image extraction, interactive form fill,
genuinely orphaned widget repair, OCR of an image-only PDF, native `pdfinfo`, and
native Poppler rendering. Form verification reopens the file and compares the
canonical field tree, page widgets, values and appearance streams. Filled text
and checkbox values render correctly in both initialized PDFium and Poppler.
Visual review found no clipping, overlap, missing text or illegible content.

environment had not been initialized. The PDF and its logical values were
correct, as the independent Poppler render showed. Initializing forms and
explicitly rendering annotations corrected the screenshots without changing the
PDF. The private observation preserves that correction rather than treating
the initial diagnostic screenshot as passing evidence.
